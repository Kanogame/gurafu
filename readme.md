# gurafu

[![Made with iced](https://iced.rs/badge.svg)](https://github.com/iced-rs/iced)

Десктопный редактор графов на Rust с пошаговой визуализацией алгоритма поиска эйлерова цикла. Граф можно нарисовать мышкой, сохранить в json, открыть обратно, а потом прокрутить по нему алгоритм Хирхольцера шаг за шагом и посмотреть, как он выбирает рёбра и откуда откатывается.

## Стек

- Rust, edition 2024
- iced 0.13 с фичами canvas, svg и tokio
- petgraph, граф хранится в StableGraph
- serde и serde_json для сохранения
- rfd для системных диалогов открытия и сохранения файла
- rand

## Как запускать

Зависимости зафиксированы в Cargo.lock, обновлять их не нужно, cargo соберёт всё сам.

```
cargo run --release
```

Важный момент: запускать надо из корня репозитория. Иконки грузятся по относительным путям вида assets/icons, и из другой директории интерфейс останется без картинок.

Готовые графы для проверки лежат в samples, открываются кнопкой Открыть файл.

## Структура папок

- src/main.rs - точка входа, три строчки
- src/gurafu_app.rs - состояние приложения, все сообщения и разбивка окна на панели через pane_grid
- src/gurafu_app/toolbar.rs - выбор инструмента: рука, узел, связь
- src/gurafu_app/file.rs - новый файл, открыть, сохранить
- src/gurafu_app/player.rs - плеер алгоритма: пуск и пауза, шаг, сброс, ползунок скорости от 0.25x до 4x
- src/gurafu_app/styles.rs - тема и стили
- src/gurafu_app/components - мелкие виджеты: кнопка с svg-иконкой, модалка, окно сообщений
- src/gurafu_app/canvas.rs и папка canvas - холст и всё вокруг него: камера, сетка, обработка мыши, отрисовка узлов и рёбер, сериализация
- src/gurafu_app/canvas/algorithms - алгоритмы. Сейчас там один Хирхольцер, рядом с ним тесты
- assets/icons - svg иконки интерфейса
- samples - примеры графов в json

## Особенности

- Граф лежит в petgraph StableGraph, поэтому индексы узлов не разъезжаются после удаления. Веса узлов и рёбер это сразу и данные, и то, что рисуется: позиция, радиус, цвет
- Узлы прилипают к сетке, а зум идёт от позиции курсора, а не от центра экрана. Мелочь, но без неё навигация раздражает
- Алгоритм спрятан за трейт GraphAlgorithm с методами step_algorithm, reset_algorithm и clear_highlights. Добавить второй алгоритм можно не трогая ни холст, ни интерфейс, состояние алгоритма это параметр типа у холста
- Один шаг это не одна итерация цикла, а переход маленького автомата состояний: проверка исходящих рёбер, выбор следующего, продвижение, откат. Поэтому на экране видно не только результат, но и как алгоритм думает
- Алгоритм работает на копии графа и вычёркивает рёбра из неё, оригинал только подсвечивается
- Сохранение это сериализация графа petgraph плюс координаты узлов, формат читаемый, файл можно править руками
- Открытие и сохранение файла асинхронные, через Task и rfd, ошибки формата показываются модалкой, а не паникой
- Интерфейс на русском
